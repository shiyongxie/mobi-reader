      朗读声音

      正在检测可用声音…

      下拉框里的声音来自系统的语音引擎，网页只能列出系统里已装好的语音包。想让手机多出几个中文人声，得先去系统里安装：

      Android：设置 → 语言和输入法 → 文字转语音（TTS）输出 → 首选引擎选「Google 语音服务」→ 点它右边的齿轮 → 安装语音数据 → 中文（中国）。装完回到本页点「刷新声音列表」。

      iOS / iPadOS：设置 → 辅助功能 → 朗读内容 → 声音 → 中文 → 下载想要的声音（如「美佳」「语舒」）。回到本页刷新。

      桌面 Chrome / Edge：声音来自 Windows 系统语音。用 Microsoft Edge 打开本页还会多出一批微软在线自然语音（如「晓晓」），无需额外安装。
